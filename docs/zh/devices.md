# 支持的设备

[English](../en/devices.md) · [Русский](../ru/devices.md) · **中文**

[BatteryTray](../../README.zh-CN.md) 可在 Windows 10/11 和 macOS 13+ 上显示无线耳机、鼠标、键盘、手柄、AirPods 和其他蓝牙设备的电量：Windows 上显示在时钟旁，Mac 上显示在菜单栏中，并在电池耗尽前提醒你。游戏设备通过它们自己的 2.4 GHz 接收器读取，使用的是厂商软件所用的同一协议，因此不需要 Razer Synapse、Logitech G HUB、SteelSeries GG、HyperX NGENUITY、Corsair iCUE 或 ASUS Armoury Crate。

下面列出的设备在 Windows 和 macOS（Apple 芯片和 Intel）上都能使用，标有 *仅 Windows* 或 *仅 macOS* 的行除外。

**状态**

- ✅ **已测试**：已在真实设备上确认可用，由开发者或用户测试。
- **支持**：按设备自己的协议读取，与厂商软件的读取方式相同（见[工作原理](how-it-works.md)），因此预期和已测试的设备一样可用。如果你的设备不行，请[提交 issue](https://github.com/qu1ncky/BatteryTray/issues) 并附上日志。

## 部分设备说明

- **Razer Barracuda X** 会在电量每变化 1% 时通过接收器发送自己的电量百分比。在它发送之前（程序刚启动时），电量显示为“—”，即“暂不知道电量”。充电时完全没有百分比——耳机的数字只会以固定速度慢慢涨到 100%——所以你看到的是它正在充电、快充满了以及已经充满。
- **Attack Shark / Rongyuan 鼠标**插上数据线后会离开接收器，通过数据线也不报告电量（厂商自己的驱动同样不显示），因此显示为充电中；拔掉数据线后，接收器会报告真实电量。
- **Attack Shark X82 PRO HE** 键盘用数据线充电时仍连接在接收器上，但此时报告的电量比实际高 20–30%，拔掉数据线后又恢复正确。很可能是键盘根据电池电压估算电量，而充电会抬高电压。没有任何信息能说明键盘插着线：接收器的回复不变，也不会出现新的 USB 设备，厂商自己的驱动显示的也是同样偏高的电量。因此数字按原样显示（[#5](https://github.com/qu1ncky/BatteryTray/issues/5)）。
- **AJAZZ T520 Max** 充电时会在电池充满之前就报告 100%，所以充电时只显示充电标志，不显示数字。
- **使用 Xenta 接收器的鼠标**（`1D57:FA60`：Attack Shark、FURYCUBE、Delux、Inphic、MAMBASNAKE）每 2 秒自己发送一次电量；BatteryTray 只是监听，不向它们发送任何内容。插线或放在充电底座上时，它们发送的数字会停住不变，因此这时显示充电标志，鼠标离开充电器几秒后会恢复真实电量。型号由这些消息中的代码区分：代码未知的鼠标会显示为无电量，它的消息会写入日志——请把 `%LOCALAPPDATA%\BatteryTray\log.txt` 中的 `Xenta` 行发到 [Issues](https://github.com/qu1ncky/BatteryTray/issues)，以便添加支持。
- **分档显示的电量**。有些设备只报告少数几档电量，所以百分比按档跳变：较老的 ASUS ROG 鼠标每档 25%，使用 Areson `FA07` / `FA08` 接收器的鼠标和 Ardor Renegade 每档 10%，VAXEE 鼠标每档 5%，Flydigi 手柄有自己的分档；Xbox 手柄只有 4 档（通过 Xbox 无线适配器和经典蓝牙），Switch 手柄有 5 档。Finalmouse 的电量是估算值，带“≈”显示，所有根据电池电压估算的电量也是如此。
- **使用 SONiX 接收器的键盘**不报告是否在充电，所以没有充电标志。
- **多个品牌共用的接收器**。许多廉价 2.4 GHz 接收器在毫不相关的产品中使用相同的 USB ID。使用这类 ID 的设备在第一次回复后才会出现在列表中，以免有人的列表里出现一把自己并没有的“休眠”键盘；在此之前，询问它的间隔会越来越长。如果你的设备在表中却没有出现，请唤醒它并等一分钟；如果仍然没有，请把 `log.txt` 发到 [Issues](https://github.com/qu1ncky/BatteryTray/issues)。
- **键盘**最多每 5 分钟询问一次（有些每 35 分钟一次），因为询问可能让键盘无法进入休眠。
- **Razer BlackShark V3** 每五分钟询问一次：询问更频繁时，耳机会断开 2.4 GHz 连接。因此它的电量可能是几分钟前的。
- **ASUS ROG Omni Receiver**：同一接收器上的鼠标和键盘会分别列出。
- **ASTRO A50** 基座的开关必须拨到 PC，并且在 ASTRO Command Center 打开时无法读取。
- **Sony PULSE 3D** 和 **Incott 鼠标**只在有变化时才报告，所以会在开机或移动后稍晚一点出现。
- **通过经典蓝牙连接的 Xbox 手柄**会在手柄发送电池报告后出现。
- **蓝牙设备**只在连接时列出：断开后 Windows 仍会保留一个过时的百分比。在 Windows 上，低功耗蓝牙设备的电量直接从设备上读取。在 Mac 上，蓝牙设备连接后且 macOS 已知道其电量时才会出现；macOS 自己不显示电量的低功耗蓝牙设备需要蓝牙权限。
- **iPhone 和 iPad**（Mac）只能通过数据线读取，并且要先信任这台 Mac——BatteryTray 从不请求配对，所以如果列表里没有你的设备，请在访达中连接一次并轻点“信任”。
- **在 Mac 上，键盘以及带键盘按键的鼠标**只有在获得“**输入监控**”权限后才能读取（macOS 要求所有打开此类设备的应用都具备该权限）。在你允许之前，这类设备会显示需要“输入监控”权限：点击列表上方提示条中的“允许”，或在“系统设置 → 隐私与安全性 → 输入监控”中打开 BatteryTray。BatteryTray 只读取电量，从不读取你输入的内容。

## 设备不在列表中？

新设备连接后几秒内就会出现，“刷新电量”会立即查找。如果你的设备没有出现，请[提交 issue](https://github.com/qu1ncky/BatteryTray/issues)，附上设备连接时下面这条命令的输出（设备接收器的 USB ID 和名称）以及日志。

**Windows**，在 PowerShell 中：

```powershell
Get-PnpDevice -PresentOnly | ? InstanceId -match '^USB\\VID_\w{4}&PID_\w{4}\\' | % { "{0}  {1}" -f $_.InstanceId.Substring(4,17), (Get-PnpDeviceProperty -InstanceId $_.InstanceId -KeyName DEVPKEY_Device_BusReportedDeviceDesc).Data }
```

日志位于 `%LOCALAPPDATA%\BatteryTray\log.txt`。诊断轮询也有帮助（把所有设备轮询一次并写入文件）：`"C:\Program Files\BatteryTray\BatteryTray.exe" --dump "%USERPROFILE%\Desktop\battery.txt"`。

**macOS**，在“终端”中：

```sh
ioreg -p IOUSB -l -w0 | awk -F' = ' '/"idVendor"/{v=$2} /"idProduct"/{p=$2} /"USB Product Name"|"kUSBProductString"/{if(n=="")n=$2} /^[ |]*}[ ]*$/{if(v!=""){gsub(/"/,"",n);printf "%04X:%04X  %s\n",v,p,n}; v=p=n=""}'
```

日志位于 `~/Library/Application Support/BatteryTray/log.txt`。诊断轮询也有帮助：`/Applications/BatteryTray.app/Contents/MacOS/BatteryTray --dump ~/Desktop/battery.txt`。

如何添加新设备：[工作原理](how-it-works.md#添加设备)。
