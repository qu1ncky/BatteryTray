# BatteryTray 功能

[English](../en/features.md) · [Русский](../ru/features.md) · **中文**

[BatteryTray](../../README.zh-CN.md) 是一款适用于 Windows 10/11 和 macOS 13+ 的免费开源程序，在时钟旁显示无线耳机、鼠标、键盘、手柄、AirPods 和其他蓝牙设备的电量，并在电池耗尽前提醒你。一个小程序管理所有设备，无需 Razer Synapse、Logitech G HUB、SteelSeries GG、HyperX NGENUITY、Corsair iCUE 或 ASUS Armoury Crate：无需账号和厂商软件，只读取电量。支持哪些设备：[devices.md](devices.md)。

## 电量始终可见

- **Windows 托盘**：显示最需要充电的设备的电量数字：正常为绿色，低于其提醒值为黄色，低于其严重值为红色，充电时为蓝色。鼠标悬停可查看全部设备。Windows 11 会把新的托盘图标收进 **^** 箭头里：把图标拖到任务栏上，就能一直看到。
- **Windows 任务栏**：打开 **设置 → 常规 → 任务栏**，列表中的前几个设备（默认三个，可设 1 到 5 个）会显示在任务栏上托盘图标的左侧，每个设备显示图标和电量，只有电量不足时才变成橙色或红色。电量不足的设备总会占到一个位置。单击打开窗口，右键打开托盘菜单。
- **Mac 菜单栏**：列表中的前几个设备，默认三个（**设置 → 常规 → 菜单栏**：1 到 5 个），每个设备显示图标和电量；平时为单色，设备电量不足时变成橙色或红色。没排上的低电量设备会占据最后一个位置。单击可查看每个设备的电量和命令。

## 一个窗口查看所有设备

- 已连接的设备以卡片显示，带百分比和充电状态；未连接的设备显示上次已知电量和获取时间。
- 每个设备的 **⋯** 菜单可以重命名、置顶、隐藏到“已隐藏”中（用眼睛按钮可恢复），或为它单独设置提醒值。
- 拖动卡片可调整顺序；菜单栏、任务栏和悬浮窗都会按这个顺序显示。
- 新设备连接后几秒内会自动出现；“刷新电量”会立即查找。

## 提醒

- **独立的窗口，而不是弹出通知**：始终置顶显示在屏幕角落，所以勿扰模式不会隐藏它，它也从不抢走游戏的焦点。
- “**{N} 分钟后提醒**”或“**充电前不再提醒**”。如果你在电脑前却没有回应，它会在 10 秒后关闭（底部的进度条显示剩余时间；可在 **设置 → 提醒** 中设为 1 到 15 秒，或一直显示到你回应），并在重复间隔（默认 10 分钟）后再次出现。你不在电脑前时，它会一直等你。
- **两个级别**：提醒值（默认 20%）和严重值（10%）；到达严重值时，即使已经稍后提醒，它也会再次出现。每个设备都可以在其 **⋯** 菜单中设置自己的值：耗电最快的耳机可以在 40% 时提醒，而鼠标可以等到 15%。
- **每种提醒都有自己的提示音**（**设置 → 提醒 → 提示音**）：低电量提醒、严重低电量提醒和“充电完成”可以分别使用系统提示音、系统的其他声音、你自己的 WAV 或 MP3 文件（不超过 10 MB，只播放前 10 秒），或者不发声。
- “**充电完成**”：支持报告充电状态的设备在插着线充满电时会通知你。

## 游戏中的悬浮窗

在 **设置 → 悬浮窗** 中启用后，按快捷键（Windows 上为 **Ctrl+Alt+V**，Mac 上为 **⌃⌥V**，也可以自定义）即可在你正在使用的屏幕上显示已连接设备的电量，持续五秒，显示在游戏和全屏应用之上，不抢占焦点或鼠标。再次按下可重新计时，也可以选择“直到再次按下”。可以选择屏幕角落，并在启用前预览。同类型的设备会显示名称。

## 真实的数字

如果设备在充电时无法报告电量，会显示充电标志，而不是过时或编造的数字。根据电池电压估算的电量带有“≈”标记。

## 浅色和深色主题，三种语言

- 跟随系统主题，也可以在 **设置 → 常规** 中选择浅色或深色。游戏中的悬浮窗始终为深色；在 Windows 上，托盘数字和托盘菜单跟随任务栏的颜色。
- 支持英语、俄语和中文。程序跟随系统语言，也可以在 **设置 → 常规 → 语言** 中立即切换。翻译位于 [`src/loc.rs`](../../src/loc.rs)，欢迎改进翻译或添加新语言。

## 更新

程序启动半分钟后检查一次，之后每 6 小时在 GitHub 上查看[最新版本](https://github.com/qu1ncky/BatteryTray/releases/latest)，这也是它唯一会连接的地方。开启自动更新时（默认开启），它会下载新版本，用 GitHub 公布的 SHA-256 摘要和文件内的版本号进行校验，并且只在窗口关闭时替换自己。关闭自动更新时，它只提示一次，由 **更新** 按钮安装。所有选项都在 **设置 → 常规 → 更新** 中：状态、更新内容、“立即检查”和自动更新开关。在 Mac 上，新版本还必须使用与正在运行的版本相同的证书签名。

## 小巧且注重隐私

Windows 上是一个约 10 MB 的 exe，Mac 上是一个约 11 MB 的应用，占用约 8 MB 内存。无需账号，没有遥测，不会更改你的设备上的任何设置：只向它们询问电量。

## Windows 和 macOS

两个平台上是同一个程序：设备列表、提醒、悬浮窗和所有支持的设备都来自同一个共享内核，而每个系统都有其用户习惯的窗口。

| | Windows | macOS |
|---|---|---|
| 电量 | 托盘中的数字；可选在任务栏上显示最多五个设备 | 菜单栏中最多五个设备，以及包含所有设备的菜单 |
| 设置 | 在主窗口中（齿轮按钮） | 独立的窗口，**设置…（⌘,）**：常规、提醒、悬浮窗 |
| 低电量提醒 | 始终置顶的窗口，右下角 | 浮动面板，右上角 |
| “充电完成”“有新版本” | Windows 通知 | macOS 通知 |
| 登录时启动 | 点击列表上方提示条中的 **启用**（开机启动设置），或完整安装时的任务计划程序任务 | 点击提示条中的 **启用**：**登录时打开** |
| 蓝牙设备 | Windows 在“设置 → 蓝牙和其他设备”中显示的电量，低功耗蓝牙设备直接从设备读取最新值；AirPods 左右耳机和充电盒分别显示；妙控键盘；Xbox 和 Switch 手柄 | macOS 已知的电量：AirPods 左右耳机和充电盒分别显示、妙控设备、耳机、手柄；任何带电池服务的低功耗蓝牙设备；通过蓝牙连接的 Logitech MX |
| 手机、平板、UPS | 通过数据线连接的 Android（文件传输模式）；USB 连接的 UPS | 通过数据线连接的 iPhone 和 iPad |
| Xbox 无线适配器 | 支持 | 不支持：macOS 没有它的驱动 |
| 权限 | 只有第三方驱动锁定接收器时才需要管理员权限（列表上方的“授予权限”） | 蓝牙；只有键盘需要“输入监控” |
| 处理器 | x64 | 一个应用同时支持 Apple 芯片和 Intel |
